👑 About AgilePanel GUI

Learn more about the AgilePanel Web GUI Dashboard companion.

AgilePanel Web Dashboard v1.1.6

AgilePanel GUI is a premium, lightweight companion web dashboard for AgilePanel (ap). Running on a secure port (8889), it provides a premium browser interface to manage your high-performance WordPress VPS stack without adding heavy daemon overhead.

📊 Real-time Diagnostics

Dynamic charts and gauges rendering CPU utilization, RAM usage, load averages, uptime, connections, and active top system processes.

🔒 Secure Architecture

Equipped with rate limiters, secure random sessions, HttpOnly cookies, CSRF double-submit token validations, path traversal blockages, and virus scans.

🔧 Local Exec Wrapping

Acts as a secure local wrapper executing optimized commands against the compiled ap CLI, mirroring SSH terminal workflows.
